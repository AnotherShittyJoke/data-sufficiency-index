ОКН Пскова — индекс достаточности данных

Предварительная оценка для НИР. Не заменяет экспертизу.

Как работать

  1. Выберите объект в таблице или в списке слева.
  2. Проверьте исходный индекс, полноту и список пропусков.
  3. Укажите подтверждённое изменение и нажмите кнопку расчёта.
  4. Для массового выбора используйте поиск объекта с максимальным эффектом.

Индекс показывает пригодность данных для предварительного анализа. Он не является решением о приспособлении объекта.
