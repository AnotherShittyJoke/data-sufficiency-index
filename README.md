# Индекс достаточности данных ОКН

Локальное приложение для оценки полноты и актуальности сведений об объектах культурного наследия Пскова.

## Запуск

```powershell
python okn-data-assessment/server.py --port 8780
```

Откройте http://127.0.0.1:8780.

Карточка показывает данные по четырём категориям, источники, доказательства и индекс. Дополнительный поиск использует открытые неофициальные источники.

Данные хранятся в `data/raw` и `data/processed`. Ошибки внешних источников записываются в `data/logs/source_errors.log`.
